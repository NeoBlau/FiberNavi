# FiberNavi

Личный навигатор для iPhone в стилистике карт из open-world игр. Карта, маршруты и ведение — реальные
(OpenStreetMap, Valhalla, Photon), Москва и Московская область проработаны в первую очередь. Оформление и голос
подгружаются из паков, которые владелец собирает из своих копий игр. Ставится сайдлоадом, в App Store не публикуется.

Подробный план и принятые решения — [docs/PLAN.md](docs/PLAN.md).

## Что умеет

- **4 темы:** `sanAndreas`, `gta5`, `rdr2`, `gta6concept`. Переключаются целиком без перезапуска: стиль карты, HUD,
  метки, шрифты, звуки, голос. Без паков работают собственные палитры и сгенерированные заглушки.
- **Карта Москвы и области:** МКАД, ЦКАД, ТТК и вылетные с номерами трасс, метро, МЦК и МЦД, аэропорты, граница
  Москвы и области, районы, города и деревни области. Отдельные дневные и ночные стили, переключение по солнцу.
  3D-здания в `gta6concept`.
- **Режим радара:** мини-карта в рамке темы, переход к полной карте с затемнением, как в игре.
- **Ведение:** поиск (Photon) с избранным и историей, 2–3 варианта маршрута, привязка к дороге, панель манёвра,
  ETA, ограничения скорости из OSM, перестроение при съезде (порог и задержка настраиваются), фоновый режим.
- **Голос:** только оригинальные реплики из пака. Целые реплики → склейка слов → UI-звук и мигание стрелки,
  если слов нет. Антиповтор 20 минут, приоритеты, болтовня не перебивает инструкции, фильтр мата, приглушение музыки.
- **Отладка:** симуляция поездки по маршруту на 40/60/90 км/ч и по GPX-треку (Настройки → Отладка).

## Установка на iPhone

**Без Mac.** Скачай `FiberNavi.ipa` из артефактов последнего зелёного запуска
[GitHub Actions](../../actions) и установи через Sideloadly или AltStore. Паки закидываются потом через
«Файлы» → FiberNavi → `UserPacks/<тема>/`.

**С Mac:**
```sh
brew install xcodegen
./scripts/build_ipa.sh          # → build/FiberNavi.ipa (паки из Assets/UserPacks попадут внутрь)
# или для разработки:
xcodegen generate && open FiberNavi.xcodeproj
```

## Сервер маршрутов и поиска

Без сервера работает только карта (OpenFreeMap). Маршруты и поиск требуют своего бэкенда:
[Backend/README.md](Backend/README.md) — Docker Compose с Valhalla, Photon и тайлами Москвы и области.
Адреса вписываются в приложении: Настройки → Сервер.

## Паки ассетов

Как собрать пак из своей копии игры и разметить голос: [tools/README.md](tools/README.md).
Куда класть готовые паки: [Assets/UserPacks/README.md](Assets/UserPacks/README.md).
Папки `raw/` и `Assets/UserPacks/` в `.gitignore`: файлы из игр не попадают в репозиторий.

## Разработка

| Проверка | Где |
|---|---|
| Сборка и unit-тесты iOS (симулятор) | CI `build-test`, локально `xcodebuild test` |
| Стили актуальны и валидны, тесты утилит | CI `tools`, локально см. `tools/README.md` |
| IPA для сайдлоада | CI `ipa` (артефакт), локально `scripts/build_ipa.sh` |

Стили карт не правятся руками: меняешь палитру в `tools/style_builder/palettes/<тема>.json`,
затем `python3 tools/style_builder/build_styles.py`. Новая тема — палитра, папка `App/Themes/<тема>/` с токенами
и одна строка в `ThemeRegistry.swift`.
